本周观察

🔍 AI 开源生态的下一轮竞争，不是“谁有更多 Agent”，而是“谁能控制 Agent 的复杂度”

模型能力正在商品化；上下文、工具权限、执行速度和失败恢复，正在成为真正的产品差异。

第一，行动层在工程化。浏览器 Agent 争夺速度，LangChain 处理编排，MCP 处理工具边界；它们共同说明 Agent 已经从聊天界面走进真实系统。

第二，记忆与上下文成为基础设施。Claude Mem 解决跨会话连续性，Headroom 解决 token 噪声。未来的好 Agent 不只是“记得多”，而是能解释为什么保留这条信息、何时丢弃它。

第三，数据入口决定上限。RAGFlow 与 Scrapling 分别从文档和网页补足知识侧。下一周值得观察的是：这些项目能否从高星仓库变成稳定、可审计的生产组件。
